# The Ur-Quan Masters - Extended Edition

Welcome! This project is a modest, unofficial fork/sub-project of
The Ur-Quan Masters, aimed at enhancing the single-player game's
atmosphere, story depth and continuity. No changes were made to
the main plot, but various plot elements have been added to make
the game world seem that much more "full", and gameplay more
satisfying. If you've played the game before, this means that it's
the same game, just with more side-plots and whatnot to find/explore.
If you've never played the game before, this version is every bit
as feature-complete as the "official release", but with some extra
atmospherics and small features.

**NOTE:** This project is no longer actively maintained, and is
here for educational purposes only.  The Ur-Quan Masters project
is a great example of how people thought doing "modern, modifiable
implementations of retro games" was going to work 20+ years ago;
in its current form, the Extended Edition patches provide some clear
guidance on how such modifications can be done against that codebase.
Each change should be self-contained in its commit, but there are
some dependencies between commits.

If desired, the game should still be fully buildable/playable, but
doing so is an exercise left up to the reader.

## Key Differences

### No voices included

They ruin EVERYTHING, even to the point of obscuring some plot
points, and making it harder for new players to win the game.

If you still want voices, you can install them, but seriously.
Don't.

### More stuff

The characters in-game mention various places and things that are,
in this version, also scattered around the galaxy for the player
to find and explore.

### Minor Bugfixes and Enhancements

Included are some fixes for small bugs that were never accepted
upstream, and now that the project Bugzilla is dead, they are kept
here rather than letting them fall down the Memory Hole.  None of
them are crash bugs or show-stoppers, but usually mild annoyances
or inconsistencies that this version aims to see annigilated... I
mean annihigated.. damn!

See https://github.com/0xDEC0DE/sc2-uqm/compare/main...uqm-ee for
a full list of changes.
